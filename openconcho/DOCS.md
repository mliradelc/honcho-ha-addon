# OpenConcho

Web UI for your self-hosted [Honcho](https://github.com/plastic-labs/honcho) memory instance.

## Configuration

| Option | Default | Description |
|---|---|---|
| `honcho_url` | `http://homeassistant:8000` | Base URL of your Honcho API |
| `access_password` | _(empty)_ | Optional basic auth password |

The Honcho add-on must be running before you open OpenConcho.
